# 资产层：Schema · 插件接口 · 方案联动

> 背景：AIGC 从业者的产出差距，一半来自资产层（角色/场景/材质/风格资产 → 一致性）。拆解动作（抠图/拆层/LoRA 训练/素材管理）已被外部工具做成熟——
> **不重做拆解，做薄壳插件接口 + 资产组织与消费**。资产本质是"调参方案"里的参数维度（参考图 / LoRA / ControlNet / 风格权重）。

## 1. 边界：什么自己做，什么用现成

| 动作 | 做法 | 现成实现（插件背后） |
|---|---|---|
| 抠图 / 分割 | 薄壳接口 `segment` | rembg / SAM2 / 一键抠图 / 即梦抠图 |
| 图层拆分 | 薄壳接口 `split_layers` | LlamaGen AI 图层拆分 / AI Line Art / SAM2 + PS 流水线 |
| LoRA 训练 | 薄壳接口 `train_lora` | LiblibAI / Kohya / 一键 LoRA 数据集工作流 |
| 素材管理 / 搜索 | 薄壳接口 `search_asset` | 即梦素材库 / Octo 资产卡 / 本地资产目录 |
| 资产 Schema + 语义标注 + 方案联动 | **产品自研** | —（差异化所在） |

原则：**接口稳定、实现可换**。背后接什么工具由用户环境决定，Skill 只定义接口契约。

## 2. 资产 Schema

```json
{
  "asset_id": "string, 资产唯一标识",
  "type": "角色 | 场景 | 材质 | 风格 | 环境 | 物体 | 自定义",
  "name": "string, 资产名（用户可读）",
  "files": ["path/url 列表（图 / LoRA / 条件图）"],
  "semantics": {
    "what": "这个资产是什么（一句话）",
    "suitable_for": "适合进哪些槽位：reference_images / lora / controlnet / style_weight",
    "restrictions": "限制：底模兼容、使用前提、版权归属"
  },
  "meta": {
    "created_from": "来源（作品/素材/训练）",
    "created_at": "ISO8601",
    "stars": "用户星标：是否高价值资产",
    "tags": ["用户标签"]
  }
}
```

## 3. 插件接口契约（薄壳）

| 接口 | 入参 | 出参 | 背后实现示例 |
|---|---|---|---|
| `extract_asset` | 图片/视频、目标类型 | 资产条目（图 + 语义草稿） | 即梦素材导入 / 手动 PS 拆解结果登记 |
| `segment` | 图片、目标主体 | 透明底素材 | rembg / SAM2 |
| `split_layers` | 图片、拆分数量 | 图层列表 | 一键图层拆分工具 |
| `train_lora` | 素材集（15–30 张）、底模、触发词 | LoRA 文件 + 使用说明 | LiblibAI / Kohya |
| `search_asset` | 类型 / 标签 / 语义描述 | 资产列表 | 即梦素材库 / 本地目录检索 |

- 每个接口的实现可插拔：用户环境有即梦 → 接即梦；有 ComfyUI → 接本地工具。
- Skill 不内置任何拆解实现，只定义契约与调用编排。

## 4. 与调参方案的联动（产品自研的核心）

翻译器生成方案时自动执行：

```text
方案生成
  ↓
资产检索：按需求类型（角色/场景/材质/风格）调 search_asset
  ↓
资产引用：命中 → 写入方案 assets 数组
  ├─ 参考图 → slot=reference_images（ref_type 按资产类型定）
  ├─ LoRA   → slot=lora（lora_weight 按用途给默认档）
  └─ 条件图 → slot=controlnet（type 按资产语义定）
  ↓
解释器：对每个引用资产解释"为什么用这个资产"（绑定需求）
  ↓
执行层：A 传资产文件/URL；B 指引用户拖入对应位置；C 指引说明上传位置
```

联动规则：
- 需求提"同一角色/产品/画风" → 必须检索对应资产；无资产时明确提示"建议先建资产（train_lora / 参考图）"并标注一致性风险。
- 资产引用必须带 reason（为什么用），解释器负责把它讲清楚。
- 资产版权：只做组织与引用，不主张归属；素材来源登记在 meta.created_from。

## 5. 参照

- **即梦 Octo 资产卡**：风格 / 角色 / 环境 / 物体 + 星标 = 给 AI 的记忆锚点 —— 资产 Schema 与星标机制的产品参照。
- **即梦素材管理**：多源导入 / 跨项目复用 / 智能搜索 —— search_asset 的体验参照。
- **一键拆层 / LoRA 数据集工作流**：拆解层已商品化的证据，插件接口背后直接接。
