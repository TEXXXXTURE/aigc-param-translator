# tools/planner.md — 快档 / 全档输出规范

> 定义交付形态。同一个调参方案，按档位裁剪输出：**快档 = 照抄就跑；全档 = 完整说明书**。
> 档位在需求解析时确认（meta.mode），执行过程中可切换（用户追问解释 → 升级全档）。

## 快档（quick）—— 默认

目标：使用者 5 分钟内照抄完成，不被解释打断。

```text
【调参方案 · 快档】目标平台：ComfyUI ｜ 预设：01-ecommerce-hero ｜ 需求：白底保温杯主图

参数表（照抄）
| 参数 | 值 |
|---|---|
| sampler | DPM++ 2M Karras |
| steps | 30 |
| cfg | 6 |
| seed | 留空（随机） |
| width × height | 1024 × 1024 |
| ref_strength | 0.75（参考实拍图） |
| negative_prompt | lowres, watermark, text, logo artifacts, distorted, cluttered reflection |

提示词（填这里）
主体：白色保温杯，磨砂不锈钢材质，500ml 规格，品牌 logo 清晰
环境：纯白背景，柔和棚拍光
质量词：product photography, 8k, clean, minimalist

最短指引（分支 C 时）
1. 采样器下拉选 DPM++ 2M Karras → 2. CFG 框填 6 → 3. 尺寸 1024×1024
→ 4. 上传实拍图到参考图位，强度 0.75 → 5. 粘贴提示词与负面词 → 6. 生成

（解释稍后可问：为什么 CFG 要 6？为什么参考强度 0.75？）
```

格式要求：
- 参数表必须可直接照抄（含默认值回填）。
- 指引只保留"在哪/做什么/填什么/预期"最简版。
- 解释区明确标注"异步可补"，一句话点到（如"写实区间压低 CFG 防塑料感"）。

## 全档（full）—— 学习 / 深度使用

目标：使用者理解每个改动项，形成调参直觉。

```text
【调参方案 · 全档】……

一、方案概览
  需求原文 / 目标平台 / 命中的预设 / 覆盖项 / 输出档位

二、参数说明书（逐项四件套）
  CFG：是什么 / 为什么这样调 / 预期效果 / 风险与观察点
  ……（每个改动项）

三、资产引用说明
  引用哪个资产 / 为什么用 / 放在哪个槽位 / 版权来源

四、执行指引
  分支说明（A/B/C 与原因）+ 步骤

五、风险清单
  每项风险的缓解与观察点
```

格式要求：
- 覆盖方案全部区块（meta / preset / params / assets / explain / exec / risk）。
- 解释逐项给四件套；资产引用逐条给 reason。
- 未确认项显式标"待确认"，不冒充确定。

## 切换规则

- quick → full：用户追问任一参数"为什么"即升级该参数为全档解释，不必整篇重写。
- full → quick：用户说"直接给我能抄的"即裁剪为参数表 + 最短指引。

## 校验清单

- [ ] 快档是否"不解释也能照抄跑通"
- [ ] 全档是否覆盖方案全部区块
- [ ] 切换规则是否按用户行为触发（而非模型自作主张）
- [ ] 未确认项是否标注
