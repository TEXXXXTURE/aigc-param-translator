# 沉默的机械师 · 人设卡（示例）

> 本资产仅为验证资产库模块 schema 与采集入库工作流而建，标注"示例"，不代表正式资产。

## 说明

赛博朋克城市边缘区的地下机械师，修义体、改机件，手艺顶尖但沉默寡言。说话只用短句，重要的事写在小纸条上。

## 人物设定

- 姓名：阿零（AZERO）
- 外貌：约 30 岁，旧军服改的工作装，左手是自改的机械臂，脸上有一道旧的焊痕
- 性格：沉默、可靠、记仇、护短；对机器的耐心远大于对人
- 背景：曾是军用维护师，城市改造后流落边缘区，开了间半地下维修铺
- 口头禅：不讲话，常用工具敲两下桌面代替"知道了"
- 动机：攒够钱把右手也换成自研的义体

## 拆解笔记（为什么有价值 / 可怎么用）

- 这类"少话但可靠"的人设适合作为短剧/漫画配角，制造反差与信息差
- 可用于出图：触发词风格参考（旧工装 + 机械臂 + 焊痕），或注入提示词上下文
- 可扩展：给他配一个话痨搭档（对照人设），同一世界观下角色关系自动成立
