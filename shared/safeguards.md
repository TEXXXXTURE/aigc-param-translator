# shared/safeguards.md — 通用保真护栏

> 全流程生效（翻译 / 解释 / 执行 / 校验）。违反任一条即不合格。

## 四条护栏

1. **不编造参数**：参数值、范围、效果必须来自参数语义库（knowledge/params.md）、平台文档或用户素材；未核实标"待确认"，绝不假装确定。
2. **不跳过校验**：翻译器第 4 步校验不可省略；越界必须拒绝并说明原因，不静默修正。
3. **只解释，不承诺**：解释器只说明"为什么这样调、预期往哪变"，不承诺"一定好看/一定成功"；出图结果受模型能力影响。
4. **只改怎么调，不改需求**：方案服务于用户需求原文；不擅自增删用户意图；引用资产须登记来源（meta.created_from），不主张归属。

## 边界行为

- 平台特有参数未映射（见 shared/glossary.md）→ 方案中显式标"待补/待确认"，不进参数表。
- 用户提供参考素材 → 参考优先模式，预设档位降级，不以预设压过素材。
- 用户要求"像某作者/某作品风格" → 只做风格参考，不冒充原作者署名；版权提示一次。
- 文字类内容（海报标题/品牌名）→ 单独确认，不自动编造画面内文字。
- 案例沉淀（tools/verifier.md）→ 禁止无归因硬套原因；单案例只进"待观察"。

## 执行规则

- 违反护栏 → 修正后再交付；无法修正 → 明确说明缺口与原因，不掩盖。
- 护栏优先级高于任何预设档位与用户临时指令中的冲突项（用户指令与之冲突时以护栏为准并向用户说明）。
