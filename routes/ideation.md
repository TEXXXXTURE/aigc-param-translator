# 思路拆解 Route — 三循环分步引导（主轴，ADR-0001）

> 本 route 是本 Skill 的**主入口**：任何需求先走「风格锚 → 构图 → 灯光」三循环，把"我要这种图"拆成三个可回答的问题，最后落成**结构化提示词串 + 平台真实存在的少数档位**。
> 依据（2026-09-29 FilmOS Studio 实测 + ADR-0001）：绝大多数预设式工作台把 steps / CFG / 采样器 / 种子全部封装掉，"翻译调参"在它们身上**没有对象可翻**；真正的空白是用户说不清楚"我要什么图"。三循环规则 = 本 Skill 的主轴，FilmOS 之类平台只是验证样本，其具体功能细节不沉淀进本仓。

## 0. 循环纪律（三套规则的共同前提）

1. **每循环先问"定了没有"**——已定 → 跳过（省时间，写明理由）；未定 → 引导定；拿不准 → 给 2–3 个候选让用户选，**不替用户审美做主**。
2. **每循环都有落盘物**——要么是资产（`style_anchor` / `camera_ref`），要么是一句明确决策；禁止"感觉定了"就往下走。
3. **三循环可乱序补**——需求先露哪一块就从哪一块开始，不必线性；但落盘前三个问题都必须有答案。
4. **命中预设卡时不跳过三循环**：预设管"档位与参数"，三循环管"思路"，两者并存；预设只作基底，三循环先跑。

## 1. A 循环 · 风格锚（抽卡定基准）

**要回答的问题**：这张图"对味"了吗？——锁定色调 / 质感 / 光影氛围的整体基调。

| 子项 | 引导问题 | 决策落盘 |
|---|---|---|
| 基调 | 冷峻写实 / 暖调胶片 / 清冷仙气 / 浓艳插画？ | 一句话风格描述（含色调 / 质感 / 氛围） |
| 基准图 | 有没有一张"对味"的参考图？没有就抽卡 / MJ 反复生成捞一张 | `style_anchor` 资产（独立于 environment 存） |
| 素材 | 用户已有参考图 / 素材里有没有直接可用的 | 引用进 plan.assets[]，说明用哪个 |

**常见坑**：风格锚没定就往下走 → 构图 / 灯光全是白调；抽卡不固定种子 → 每次都不一样无法对比。
**产出**：风格锚基准图（或明确"跳过，用文字描述"）+ 一句风格描述。

## 2. B 循环 · 构图（定机位 / 景别 / 画幅 / 比例）

**要回答的问题**：怎么拍？——机位、景别、画幅、主体比例（含巨物感）。

| 子项 | 引导问题 | 决策落盘 |
|---|---|---|
| 机位 / 景别 | 中景(腰部以上) / 特写(面部) / 越肩 / 仰拍 / 鸟瞰，选哪个？ | 机位决策 |
| 画幅 | 16:9 / 9:16 / 1:1 / 2.39:1 | 画幅决策 |
| 主体比例 | 有没有"巨物感 / 压迫感 / 空间感"需求？ | 比例手法（低机位 + 小人物参照 + 对比元素） |
| 白模 blockout | 复杂构图要不要先搭空间？ | 3D 预演静帧 / 手动想象描述 → `camera_ref` 资产 |

**常见坑**：巨物感只说"巨大"不说"怎么拍"——低机位 + 参照物才是实现手段；画幅忘了定 → 平台默认 1:1 出片不符预期。
**产出**：机位 + 画幅 + 比例手法决策；有需要时 `camera_ref` 资产。

## 3. C 循环 · 灯光（定色温 / 光比 / HDR 方向 / 软硬光）

**要回答的问题**：光从哪来、什么性质？——最难用文字描述的一环，优先用参考图 / 3D 摆灯代替写词。

| 子项 | 引导问题 | 决策落盘 |
|---|---|---|
| 色温 | 暖(烛火 / 黄昏) / 冷(月光 / 清冷) / 中性？ | 色温决策 |
| 光比 | 高对比(硬光剪影) / 柔光漫射 / 平光？ | 光比决策 |
| HDR 方向 | 顺光 / 侧光 / 逆光 / 顶光 / 底光？主光源在哪？ | 光源方向决策 |
| 软硬 | 硬光出投影、柔光出渐变？ | 软硬决策 |

**常见坑**：灯光全用"氛围感"糊过去 → 提示词无对象可翻；逆光 = 剪影，注意主体识别度。
**产出**：色温 + 光比 + 方向 + 软硬四项决策，最好带 1 张灯光参考图。

## 4. 落盘：三循环决策 → 提示词串 + 档位

三循环全部有答案后：

1. **组装结构化提示词**（五段式）：主体 / 环境 / 风格（含风格锚描述）/ 光线（含灯光四项）/ 质量词。
2. **平台档位**：质量（低 / 中 / 高）、张数、画幅——预设式平台到此为止，直接出图。
3. **原子参数翻译仅 ComfyUI 类**：只有 ComfyUI / SD WebUI 这类原子化产品才进入 `schema/params.schema.json` 槽位填充（steps / CFG / 采样器 / seed…）；预设式平台**不翻裸参**（ADR-0001）。

## 5. 校验区（扣分项）

- [ ] 三个循环各自"定了没有"都有明确答案（跳过也算，但要写明理由）
- [ ] 风格锚：有基准图或明确用文字描述
- [ ] 构图：机位 + 画幅明确；有巨物感需求时有比例手法
- [ ] 灯光：色温 / 光比 / 方向 / 软硬四项不全空
- [ ] 落盘：五段式提示词 + 平台档位；ComfyUI 类才填原子参数
