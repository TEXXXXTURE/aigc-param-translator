# 02 · 赛博朋克海报卡

> 用途：赛博朋克 / 科幻海报 / 主视觉 / 电影级氛围图。核心诉求：霓虹光影、合成感、电影感构图。

## 适用需求特征

- "赛博朋克""科幻海报""霓虹""电影级主视觉"
- "合成感""未来城市""赛博街区""发光元素"

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 风格化向模型；或通用写实 + 风格词强化；未指定用平台默认 |
| 采样器 | DPM++ 2M Karras 或 DPM++ SDE（细节更锐利，耗时略增） |
| 步数 | 30–35（风格复杂场景建议更足步数） |
| CFG | 7–9（风格化区间；高于写实档） |
| 分辨率 | 海报按载体：2:3 / 3:4 竖版优先；宽幅主视觉 16:9 |
| 种子 | 随机起步；构图满意后固定种子做光影微调 |
| 提示词结构 | 场景（未来城市/街区）+ 光线（霓虹青紫/雨夜反光）+ 风格（电影感/景深）+ 质感词（体积光/颗粒） |
| 负面提示词 | 通用 + 额外：过曝、死黑、塑料感、文字乱码 |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 32,
  "cfg": 8,
  "aspect_ratio": "2:3",
  "ref_type": "style",
  "ref_strength": 0.65,
  "negative_prompt": "overexposed, dead blacks, plastic look, garbled text, lowres"
}
```

## 可覆盖声明

- 用户提供"想要的感觉"参考图：**风格参考优先**（ref_type=style，0.5–0.75），主体内容由提示词控制。
- 用户要求"某城市某街区实景感"：切 content 参考 + 降低风格权重，避免纯幻觉。
- 需要画面内文字（如海报标题）：单独确认文字内容与平台文字能力，不自动编造。

## 常见坑

- CFG > 12 → 霓虹过曝、色块粘连。
- 无风格参考时全靠提示词 → "电影感"很难单靠词达成，建议至少一张风格锚图。
- 海报带字 → 多数模型对文字不友好，先无字出图 + 后期排字，比硬出带字图稳。

## 校验区（扣分项）

- [ ] 是否给出风格参考策略（style ref 权重档位）
- [ ] 画面内文字是否单独确认，未自动编造
- [ ] 光影 / 构图关键词是否成组（不止"赛博朋克"一个词）
- [ ] 是否说明"电影感"依赖参考锚图而非纯提示词
