# 03 · 世界观美术设定卡

> 用途：世界观美术 / 概念设定 / 场景氛围 / 环境概念图 / 系列一致性图。核心诉求：**一致性** —— 同一个世界反复出现不崩。

## 适用需求特征

- "世界观""概念设定""场景氛围""环境概念图"
- "系列图""同一世界多个场景""让人想写小说的那种图"

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 写实/风格化均可，关键在**资产一致性**而非模型 |
| 采样器 | DPM++ 2M Karras |
| 步数 | 30–35（大场景细节） |
| CFG | 6–8 |
| 分辨率 | 横版优先（16:9 / 2.35:1 电影比例）；系列统一比例 |
| 种子 | 系列一致性：固定基底种子 + 共享风格参考 |
| 提示词结构 | 世界观设定卡：时代/地理/气候 + 核心建筑/生物/文明符号 + 光线氛围 + 镜头（大远景/航拍） |
| 资产策略 | **必须有资产锚点**：风格资产（统一氛围）+ 环境资产（关键地标）+ 角色资产（如有） |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 32,
  "cfg": 7,
  "aspect_ratio": "16:9",
  "ref_type": "style",
  "ref_strength": 0.7,
  "assets": ["style-anchor", "landmark-ref", "character-ref"]
}
```

## 可覆盖声明

- 系列一致性 = **资产层策略**：先建"世界观风格锚图"（1–2 张定调），后续每张都以它做风格参考；关键地标做环境资产复用。
- 用户已有世界观文字设定：先翻译成设定卡（时代/地理/符号），再进提示词结构。
- 无资产锚点时：先出 1 张"定调图"，确认后作为后续参考锚点（第一次任务分两步）。

## 常见坑

- 无锚点直接连出 → 每张风格漂移，凑不成一个世界。
- 提示词只写"宏大""史诗" → 模型无法定位，出图随机。
- 只固定种子不固定资产 → 单张好看，系列不连贯。

## 校验区（扣分项）

- [ ] 是否给出"定调图先行"或已有资产锚点的策略
- [ ] 设定卡是否含时代/地理/符号（可复现的锚点词）
- [ ] 系列图是否统一比例与光线基调
- [ ] 是否提醒资产版权与来源标注
