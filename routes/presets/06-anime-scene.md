# 06 · 动漫插画场景卡

> 用途：动漫插画 / 二次元场景 / 国漫 / 厚涂 / 插画风。核心诉求：**画风统一、线条与上色风格稳定**。

## 适用需求特征

- "动漫""二次元""插画""国漫""厚涂""赛璐璐""日系"
- "插画场景""单格/多格画面""系列插画"

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 动漫/插画向模型或风格参考；未指定用平台默认 + 风格锚图 |
| 采样器 | DPM++ 2M Karras（动漫常用）；Euler a（部分风格更顺手，需试） |
| 步数 | 25–30（动漫通常比写实更快收敛） |
| CFG | 6–8（风格化区间） |
| 分辨率 | 插画横竖均可；系列统一比例 |
| 种子 | 固定种子 + 风格参考共用 |
| 提示词结构 | 画面内容（主体+动作+场景）+ 画风锚点（厚涂/赛璐璐/水彩/国漫质感）+ 线稿风格（粗细/留白）+ 氛围 |
| 资产策略 | 风格参考优先（style ref 0.55–0.7）；长期做同画风 → 风格 LoRA（train_lora 插件接口） |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 28,
  "cfg": 7,
  "ref_type": "style",
  "ref_strength": 0.6,
  "negative_prompt": "photorealistic, 3d render, lowres, extra limbs"
}
```

## 可覆盖声明

- 用户有"想要的画风"参考图：风格参考优先；多张参考时权重取中（0.5–0.65），防止风格锁死构图。
- 用户明确要求"像某画师/某作品风格"：只能做风格参考，不得冒充原作者署名。
- 系列插画：定调图先行（同 03 世界观卡的锚点策略）。

## 常见坑

- 反面提示词忘了"写实感"排除 → 插画混入照片质感。
- 风格权重过高 → 人物动作构图被锁死；过低 → 每张画风漂移。
- "厚涂""水彩"等画法词与参考图冲突时，以参考图为准，词只做辅助。

## 校验区（扣分项）

- [ ] 画风锚点是否具体（厚涂/赛璐璐/水彩…，非"好看"）
- [ ] 是否给出风格参考策略与权重
- [ ] 负面提示词是否排除写实/3D 质感
- [ ] 是否避免"像某作者风格"的署名冒充
