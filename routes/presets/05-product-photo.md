# 05 · 产品写实图卡

> 用途：产品写实图 / 静物摄影 / 材质质感 / 光影写实 / 场景图。核心诉求：**材质真实、光影可信、像棚拍**。

## 适用需求特征

- "产品写实""静物摄影""材质质感""棚拍""光影写实"
- "产品放进场景""氛围图""广告大片感"

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 写实摄影向模型；未指定用平台默认写实模型 |
| 采样器 | DPM++ 2M Karras（或 DPM++ SDE 加强质感） |
| 步数 | 30–35 |
| CFG | 5–6.5（写实偏低，防"过度锐化/塑料感"） |
| 分辨率 | 按载体：1:1 电商 / 4:5 社媒 / 16:9 场景广告 |
| 种子 | 固定种子做光影方案对比 |
| 提示词结构 | 主体（材质+表面处理+瑕疵控制）+ 光线（光源类型/方向/柔硬）+ 环境（背景/桌面/景深）+ 镜头（焦距/景深效果） |
| 负面提示词 | 通用 + 额外：塑料感、过度锐化、错误反射、伪影 |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 32,
  "cfg": 5.5,
  "aspect_ratio": "4:5",
  "ref_type": "content",
  "ref_strength": 0.75,
  "negative_prompt": "plastic look, oversharpened, wrong reflections, artifacts, lowres"
}
```

## 可覆盖声明

- 用户有产品实拍图：content 参考优先（0.7–0.85），提示词只写光线与场景，材质由实拍图决定。
- 材质描述必须具体：镜面/哑光/磨砂/拉丝/皮革/织物——抽象的"高级质感"不进入提示词。
- 场景广告图：切场景构图时保留产品参考 + 控制景深词，防止产品被背景吃掉。

## 常见坑

- CFG 过高 → 过度锐化、塑料质感，写实变"CG 味"。
- 光线词过少 → 平光死板；过杂 → 多光源阴影矛盾。
- 产品参考权重不足 → 材质漂移，不像同一个产品。

## 校验区（扣分项）

- [ ] 材质描述是否具体（非"高级""质感"抽象词）
- [ ] 光线是否给出光源类型与方向（可执行）
- [ ] 有实拍图时是否走 content 参考 + 高权重
- [ ] 是否避免编造产品参数（如具体工艺规格）
