# 00 · 默认兜底卡（通用档位）

> 用途：未命中任何预设 / 需求模糊 / 多风格混合时使用。保证"能出图、不翻车"，再由用户细化。

## 适用需求特征

- 未命中 01–06 任何特征。
- 需求描述模糊（只有"好看""高级"等无具体方向词汇）。
- 多风格混搭且未定主基调。

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 平台默认最新写实模型（如 doubao-seedream / SDXL 系）；未指定不猜具体版本 |
| 采样器 | DPM++ 2M Karras（通用最稳）；无此选项用平台默认 |
| 步数 | 25–30（质量与速度折中） |
| CFG | 6–7（通用区间，写实略降、风格化略升） |
| 分辨率 | 平台默认比例；用户未指定用 1:1（1024×1024 或平台对应） |
| 种子 | 随机；出图后建议固定种子便于复现 |
| 提示词结构 | 主体 / 环境 / 风格 / 光线 / 质量词，五段式 |
| 负面提示词 | 通用：变形、多余手指、低质量、模糊、水印 |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 28,
  "cfg": 6.5,
  "seed": null,
  "width": 1024,
  "height": 1024,
  "negative_prompt": "lowres, bad anatomy, extra fingers, blurry, watermark, text"
}
```

## 可覆盖声明

本卡为最宽松基底，**任何参数都可被用户需求或预设命中覆盖**。命中具体预设后以预设为准。

## 常见坑

- CFG 过高（>12）导致色彩过饱和、轮廓生硬；过低（<3）导致主体散架。
- 步数过低（<15）细节不足；过高（>40）收益递减且耗时。
- 种子不固定导致"每次都不一样"，难以迭代对比。
