# 01 · 电商主图卡

> 用途：电商主图 / 商品图 / 白底图 / 卖点展示 / 详情页首图。核心诉求：主体清晰、卖点可读、背景干净可控。

## 适用需求特征

- "电商主图""商品主图""白底图""详情页首图"
- "突出产品质感 / 卖点""多角度商品图""套图"

## 默认档位

| 维度 | 档位 |
|---|---|
| 模型 | 写实产品向模型（如 doubao-seedream / SDXL 写实系），未指定用平台默认写实模型 |
| 采样器 | DPM++ 2M Karras（或平台默认） |
| 步数 | 28–32（细节要求高于通用档） |
| CFG | 5.5–7（主体写实区间；白底图可略降防塑料感） |
| 分辨率 | 1:1 或 4:5（平台详情页常用）；套图保持统一比例 |
| 种子 | 套图场景：固定基底种子 + 每张微调，保证一致性 |
| 提示词结构 | 主体（品牌+品名+材质+规格）+ 环境（白底/场景）+ 光线（柔光/棚拍）+ 质感词 |
| 负面提示词 | 通用 + 额外：文字水印、错误 logo、变形、反射杂乱 |

## 原子参数建议

```json
{
  "sampler": "DPM++ 2M Karras",
  "steps": 30,
  "cfg": 6,
  "seed": null,
  "aspect_ratio": "1:1",
  "ref_type": "content",
  "ref_strength": 0.7,
  "negative_prompt": "lowres, watermark, text, logo artifacts, distorted, cluttered reflection"
}
```

## 可覆盖声明

- 用户提供商品实拍图时：**参考优先**，ref_strength 以实拍图为准（0.6–0.85），提示词描述材质与卖点即可。
- 用户要求"多场景套图"：固定种子基底 + ControlNet（如 lineart/depth 保形）控制构图一致性。
- 用户要求"突出卖点文字"：文字类参数（平台 prompt 内文字能力）单独确认，不猜。

## 常见坑

- 白底图 CFG 过高 → 塑料质感、边缘光晕。
- 参考图权重过低 → 产品特征漂移；过高 → 背景也被锁定。
- 套图不固定种子 → 每张产品形态不一致，无法成组。

## 校验区（扣分项）

- [ ] 是否有明确的参考图策略（实拍图 → 权重档位）
- [ ] 套图是否给出种子与一致性方案
- [ ] 卖点 / 规格是否进入提示词结构（不是只写"产品"）
- [ ] 是否避免编造具体品牌参数
